TestDummy

Chrome Extension for Automated Test Form Filling

TestDummy is a Chrome extension designed to automatically fill signup forms with test accounts for local and staging environments. Perfect for developers who need to quickly test user flows without manually entering form data every time.

🚀 Quick Setup

Easy one-time setup with customizable test profiles for different scenarios.

⌨️ Keyboard Shortcuts

Use Alt+Shift+F to instantly fill forms without clicking through menus.

🎯 Smart Detection

Automatically detects form fields and fills them with appropriate test data.

📧 Email Versioning

Generates unique test emails to avoid conflicts during testing.

🔒 Privacy First

All data stays local - no external servers, no tracking, no data collection.

🌐 Local & Staging

Works on localhost and staging environments for comprehensive testing.
